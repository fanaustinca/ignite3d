# Fasteners & spacers review (family `fasteners`)

Rule: `canon/rules_fasteners.py`. Overrides generated by `gen_overrides_fasteners.py` (run after `batch.py`): male snaps,
cleaned nut/standoff female snaps, 3203 + 1523 exclusions. All 155 SKUs with STEP files (incl. 2800 x22, 2802 x18, 1501 x37, 1516 x35) converted (downloader finished);
11 `3203-*` bundles excluded (`{"exclude": true, "notes": "bundle"}`, not converted).

## Rules
- **Screws 2800/2802**: head = largest-radius boss; under-head plane = start of the shank boss nearest the head; frame puts it at y=0, axis through
  origin, head on +Y. Male `underhead` (`m4_hole`, p=(0,0,0), n=(0,-1,0)) emitted via override `male`.
- **Nuts 2811/2812**: axis from the bore; flat bearing face = end whose end-plane has the larger outer radius (nylon dome end is smaller); that face at y=0, body +Y.
  Override replaces the detector's 8 fragmentary bore snaps by two clean tapped `m4_hole` snaps `n0a` (y=0, n -Y) and `n0b` (y=H, n +Y).
- **Washers/shims/spacers/pattern spacers (2801, 2810, 2807, 1500, 1520, 1526, 1504, 1505, 1506, 1517, 1531)**: axis Y, centred on the mesh extent. Auto snaps kept.
- **Standoffs 1501/1516**: axis Y, centred; override replaces detector snaps (r2.0 + r1.65 duplicates set back 0.35 mm) by two tapped `m4_hole` snaps exactly at the end faces (y = +-L/2, depth L). 1516 outer profile = hexagon 7.0 mm A/F with corners turned to 8.0 mm dia (r=4.0 arcs) = the REX shape.
- **2904 hole reducer**: flange underside at y=0, spigot (r=7.0 = 14 mm) toward -Y, flange (r=7.8) toward +Y, total 2 mm. Male `flange_underside` (`bearing_14mm`, n=(0,-1,0) = insertion). Female m4 (r=2.0, untapped) snaps on both faces from the detector.
- Important: the converter's BRep bbox is inflated by up to ~0.15-0.33 mm (OCC tolerance), e.g. screws show +0.146 mm past the tip, nut +0.33. Rule measures true extents from the tessellated mesh. `out/*.json` `bbox` for these parts is therefore slightly oversized (not fixed - converter-level).
